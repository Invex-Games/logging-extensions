Remarks

Use this logger before building a host or after stopping one. It does not inherit the host's providers, configuration, or services. The default category filter permits Microsoft entries at Microsoft.Extensions.Logging.LogLevel.Warning and above; the callback can add further filtering rules.

LogStartupInfo(ILogger, string?, string?, string?, string?)

Writes an information-level startup message with explicit application, version, machine, and environment values, if that level is enabled.

public static void LogStartupInfo(ILogger logger, string? applicationName, string? version, string? machineName, string? environment)

Parameters

logger ILogger

The logger that receives the startup message.

applicationName string

The application name, or null/empty to display Application.

version string

The version, or null/empty to omit it. Leading v and V characters are removed before a single v prefix is added.

machineName string

The machine name, or null/empty to omit the on clause.

environment string

The environment name, or null/empty to omit the in ... configuration clause.

Remarks

The message order is Started {application} v{version} on {machine} in {environment} configuration. Optional clauses include their own leading space, and whitespace-only values are retained. The template is Started{AppName}{Version}{MachineName}{Environment}: MachineName receives the machine clause, and Environment receives the environment clause. Structured values include these formatted clauses rather than the raw inputs. Logging failures from the supplied logger are not caught.

LogStartupInfo<T>(ILogger, IHostEnvironment?)

Writes an information-level startup message using the assembly containing T.

public static void LogStartupInfo<T>(ILogger logger, IHostEnvironment? environment = null)

Parameters

logger ILogger

The logger that receives the startup message.

environment IHostEnvironment

An optional host environment whose Microsoft.Extensions.Hosting.IHostEnvironment.EnvironmentName is included in the message. Its Microsoft.Extensions.Hosting.IHostEnvironment.ApplicationName does not supply the application name.

Type Parameters

T

A type whose assembly supplies the application name and assembly version.

Remarks

Uses the assembly's simple name and AssemblyName.Version, rather than its file or informational version, and System.Environment.MachineName. The explicit-value overload determines formatting and skips the message when Microsoft.Extensions.Logging.LogLevel.Information is disabled. Calling this method does not start a host or verify that it started successfully.
