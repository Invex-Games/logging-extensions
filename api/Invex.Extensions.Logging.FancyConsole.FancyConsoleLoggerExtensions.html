Adds a fancy console logger provider to the logging pipeline using configuration bound from the Logging:FancyConsole configuration section (see FancyConsoleLoggerConfiguration).

Parameters

builder ILoggingBuilder

Returns

ILoggingBuilder

The same Microsoft.Extensions.Logging.ILoggingBuilder instance so that additional calls can be chained.

Remarks

The provider is registered with the alias "FancyConsole", so it can be configured and filtered via the Logging:FancyConsole configuration section. Calling this method multiple times registers the provider only once. Existing logging providers remain registered; call ClearProviders() first when replacing the default console provider.

AddFancyConsole(ILoggingBuilder, Action<FancyConsoleLoggerConfiguration>)

Adds a fancy console logger provider to the logging pipeline and applies additional configuration via a delegate.

Remarks

The delegate is applied whenever options are created, including after a configuration reload. Repeated calls register one provider but add each supplied configuration delegate in call order.
