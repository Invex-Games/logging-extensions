Specifies how the fancy console logger renders an exception attached to a log entry.

public enum FancyConsoleExceptionFormat

Fields

Full = 0

Writes the result of System.Exception.ToString(), including inner exceptions and stack traces, using ExceptionTextStyle.

Hidden = 3

Does not write exceptions. Only the formatted message is written.

Pretty = 1

Writes the exception using Spectre.Console's exception formatter, which highlights the exception type, message, methods, and source locations and shortens paths, types, and method names.

Falls back to Full if Spectre.Console cannot construct the exception renderable, such as for some exceptions with unthrown inner exceptions on .NET Framework. UseColors disables styling without changing this layout.

Summary = 2

Writes only {TypeName}: {Message} for the exception and each inner exception, joined by ---> , without stack traces.

Follows the System.Exception.InnerException chain. This does not enumerate every branch of an System.AggregateException. In SingleLine and Minimal, the summary follows the message after | , with line breaks in the summary replaced by spaces.
