Remarks

Reloadable configuration sources update these options through the options monitor. Writers use the current options for each entry or buffered batch, so already queued entries can use new routes.

Properties

FileSizeLimitBytes

Gets or sets the size-based rollover threshold, in bytes. An existing active file is rolled over before its size plus the pending UTF-8 entry or batch size would meet or exceed this value. Defaults to DefaultFileSizeLimitBytes (100 MiB).

public long FileSizeLimitBytes { get; set; }

Property Value

long

Remarks

Entries and batches are not split, so a new active file can exceed this threshold. Zero or negative values cause every write to an existing active file to roll over; they do not disable rollover.

LogDirectory

Gets or sets the directory where log files are written. May be an absolute path, or a path relative to the application's current working directory. The directory is created automatically if it does not exist. Defaults to DefaultLogDirectory.

public string LogDirectory { get; set; }

Property Value

string

LogName

Gets or sets the base file name (without extension) of the log file. The active log file is named {LogName}.log before any configured group and level suffixes are appended. Rolled-over files append _{timestamp} to the complete name before the extension. Defaults to System.AppDomain.CurrentDomain.System.AppDomain.FriendlyName when the configuration instance is created. An empty string is used literally.

public string LogName { get; set; }

Property Value

string

Remarks

Names and mapped suffixes are used verbatim. Use file name components without an extension or directory separators, and set the destination directory through LogDirectory.

MaxTotalSizeBytes

Gets or sets the retention threshold, in bytes, for archives of each resolved base name, including group and level suffixes. On rollover or initial file creation, if qualifying archives meet or exceed this value, the oldest archive by creation time is deleted. Defaults to DefaultMaxTotalSizeBytes (10 GiB).

public long MaxTotalSizeBytes { get; set; }

Property Value

long

Remarks

At most one archive is deleted per check. Active destinations are excluded, and the active file's size is not counted. This is not a hard disk quota. Zero or negative values delete the oldest qualifying archive whenever a retention check finds one; they do not disable retention.

PerGroupLogName

Gets or sets file name suffixes for groups supplied by a logging scope's Group property. A matching nonempty suffix is appended to LogName, separated by an underscore, before any PerLevelLogName suffix. Missing or unmapped groups and mapped null or empty values add no group suffix or separator. Empty by default, with case-sensitive group matching; a replacement dictionary's comparer is respected.

public Dictionary<string, string?> PerGroupLogName { get; set; }

Property Value

Dictionary<string, string>

Remarks

The innermost nonempty string Group value wins. An unmapped inner group suppresses an outer group's mapping. Null, empty, and non-string scope values leave the outer group effective. The group is captured when logging; its mapping is resolved when the entry is written.

PerLevelLogName

Gets or sets per-Microsoft.Extensions.Logging.LogLevel file name suffixes. A matching nonempty suffix is appended to LogName, separated by an underscore. When a group also matches PerGroupLogName, its suffix precedes the level suffix: {LogName}{groupSuffix}{levelSuffix}.log. Missing levels and mapped null or empty values add no level suffix or separator. Empty by default.

public Dictionary<LogLevel, string?> PerLevelLogName { get; set; }

Property Value

Dictionary<LogLevel, string>

RolloverInterval

Gets or sets the time interval after which the active log file is rolled over, based on the file's creation time. Use Infinite to disable time-based rollover. Defaults to DefaultRollingInterval (Day).

public FileRolloverInterval RolloverInterval { get; set; }

Property Value

FileRolloverInterval

Remarks

Checked only before writes. Intervals measure elapsed time rather than calendar boundaries; a month is 30 days and a year is 365 days. New files receive the writer's current UTC creation time.

Parameters

suffix string

The suffix appended to the application's friendly name. An empty string leaves a trailing underscore.

Remarks

Uses System.AppDomain.CurrentDomain.System.AppDomain.FriendlyName rather than the current LogName. For an application named MyApp, SetLogNameSuffix("worker") produces MyApp_worker.log before group and level suffixes are applied.
