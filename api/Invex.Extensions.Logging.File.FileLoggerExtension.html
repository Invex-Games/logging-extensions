AddFile(ILoggingBuilder, bool)

Adds a file logger provider to the logging pipeline using configuration bound from the Logging:File configuration section (see FileLoggerConfiguration).

public static ILoggingBuilder AddFile(this ILoggingBuilder builder, bool buffered = true)

Parameters

builder ILoggingBuilder
buffered bool

When true (the default), log entries are queued and written to disk by a dedicated background thread, minimizing logging overhead on application threads. When false, each log entry is written synchronously on the calling thread, with stream buffers flushed before the call returns when writing succeeds. Persistent write failures cause entries to be dropped.

Returns

ILoggingBuilder

The same Microsoft.Extensions.Logging.ILoggingBuilder instance so that additional calls can be chained.

Remarks

The provider is registered with the alias "File", so it can be configured via the Logging:File configuration section. Repeated calls with the same buffered value register that provider only once. Calling with both values registers both providers and can duplicate output. Stream flushing does not guarantee persistence through power loss or storage failure.

BeginGroupScope(ILogger, string?)

Begins a structured scope whose Group property selects a file name suffix from PerGroupLogName. Disposing the scope restores the outer group, if any. Null or empty group names are ignored, leaving an outer group effective.

public static IDisposable? BeginGroupScope(this ILogger logger, string? groupName)

Parameters

logger ILogger

The logger on which to begin the scope.

groupName string

The group name to match against the configured group mappings.

Returns

IDisposable

The underlying scope token, or null when the logger does not create scopes.

Remarks

This creates a standard logging scope, so other providers that consume scopes can also see its Group property. The file logger uses the property for routing without rendering it in log lines. An unmapped nonempty group uses the normal level/default destination, even inside a mapped group.

logger is null.
