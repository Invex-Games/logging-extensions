ExceptionTextStyle

Gets or sets the Spectre.Console style string used for Full and Summary exception text. A null or whitespace value disables styling; a value that is not a valid style uses DefaultExceptionTextStyle. Defaults to DefaultExceptionTextStyle ("red1").

public string? ExceptionTextStyle { get; set; }

IncludeScopes

Gets or sets whether active logging scopes are shown after the category, separated by => , in the Standard and SingleLine layouts. Detailed always shows scopes and Minimal never does. Defaults to DefaultIncludeScopes (false).

public bool IncludeScopes { get; set; }

Property Value

bool

Remarks

Message-template scopes (for example, logger.BeginScope("Order {OrderId}", 42)) are shown as their formatted text. Other key/value scopes are shown as comma-separated Key=Value pairs, and any other scope object is shown using ToString(). Null and empty scopes are skipped.

LevelStyles

Gets or sets per-LogLevel Spectre.Console style strings (for example, "bold red", "#ff8800", or "black on yellow") used for each entry's level-colored text. A mapped null or whitespace value disables styling for that level. Missing levels and values that are not valid styles use the built-in defaults: grey (Trace), seagreen3 (Debug), skyblue1 (Information), gold1 (Warning), darkorange (Error), and fuchsia (Critical). Empty by default.

public Dictionary<LogLevel, string?> LevelStyles { get; set; }

TimestampFormat

Gets or sets a .NET date and time format string for entry timestamps, formatted with the invariant culture. When null or empty (the default), the layout's default is used: HH:mm:ss.fff for Standard and SingleLine, and yyyy-MM-dd HH:mm:ss.fff zzz for Detailed. The Standard header line always shows the date and UTC offset. Ignored by Minimal.

public string? TimestampFormat { get; set; }

Property Value

string

UseColors

Gets or sets whether level and exception styles are applied. When false, all output is written without styling, including Pretty exceptions. Defaults to DefaultUseColors (true).

public bool UseColors { get; set; }

bool

Remarks

Even when enabled, colors are only emitted if the console supports them. Spectre.Console detects terminal capabilities and honors the NO_COLOR environment variable.
