Note

DocFX generates this reference from the compiled libraries and their XML documentation. Assembly metadata includes the registration methods declared in C# 14 extension blocks, which source-based extraction in DocFX 2.78.5 omits. Build first so the API and comments are current.

From the repository root:

dotnet build Invex.Extensions.Logging.slnx --configuration Release
docfx docfx.json --warningsAsErrors

The site is generated in _site/. Add --serve to the DocFX command to preview it locally. Files under api/ with a .yml extension are generated; edit source XML comments or Markdown pages instead.

The Atom BuildDocs target also generates the site from existing Release assemblies; it does not compile the libraries. Run the Release build above first, including before using ServeDocs.
