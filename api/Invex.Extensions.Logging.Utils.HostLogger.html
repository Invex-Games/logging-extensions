public sealed class HostLogger
Inheritance
object
HostLogger

Remarks

CreateHostLogger(Action<ILoggingBuilder>?) creates this wrapper with the category Host. When constructing it directly, supply a factory whose ownership can be transferred to this wrapper; disposing it can also affect other loggers created by that factory. The wrapper does not add filtering or catch logging failures.
