Invex.Extensions.Logging

Useful utilities for Microsoft.Extensions.Logging: a readable, styled console logger, a rolling file logger, and helpers for logging before the host starts. The providers plug into the standard logging pipeline, so they work with ASP.NET Core, the Generic Host, or a manually created ILoggerFactory.

Packages

Package What it does
Invex.Extensions.Logging.FancyConsole A colorful, readable console logger built on Spectre.Console, with multiple layouts, per-level styles, scopes, pretty exceptions, and standard-error routing.
Invex.Extensions.Logging.File A dependency-light file logger with size- and time-based rollover, retention limits, routing by scoped group and log level, and buffered or synchronous writing.
Invex.Extensions.Logging.Utils Helpers for creating a logger before a host is built, owning its factory, and logging startup information.
